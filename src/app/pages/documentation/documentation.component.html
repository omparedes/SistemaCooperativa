Arquitectura de Base de Datos (ACID) y Seguridad

Toda la lógica financiera crítica se ejecuta directamente en PostgreSQL (Supabase) mediante Stored Procedures (RPCs) con el patrón SECURITY DEFINER. Ante cualquier error de red o validación, la transacción completa hace ROLLBACK automático — no quedan estados intermedios.

Soft Deletes y Concurrencia

Sin borrados físicos financieros. Uso de deleted_at + anulado_por + motivo_anulacion, bloqueo FOR UPDATE en cobros/anulaciones y control optimista p_updated_at en gestión de ingresos internos y tarjeta.

Row Level Security (RLS)

Políticas por rol (get_my_rol()): Administrador, Caja y Asistente (alcance restringido en RPCs). El cliente usa clave anon en environment.ts; credenciales service_role jamás se incluyen en frontend.

Triggers, Realtime y Auditoría

Stock, saldos bancarios atómicos, trazabilidad narrativa en audit_logs y canales Supabase Realtime activos en bancos, gastos y pagos individuales.

Frontend, Reportes y Despliegue en Cloudflare Pages

Frontend Angular 22.3.0 y Fuentes de Verdad

  • Componentes 100 % Standalone con rutas lazy (loadComponent), reactividad con Signals, ChangeDetectionStrategy.Eager y Zone.js.
  • Fuente única de deuda fn_deudas_pagador y resumen set-based para listados masivos en Cuenta Corriente, Caja, Estados de Cuenta, Asambleas y Portal Público (/consultas).
  • Exportación Excel con xlsx cargado bajo import() dinámico (incluyendo libro contable de 9 hojas en /reportes/contable y central de 4 hojas), más PDFs A4/80mm con pdfmake y gráficos ApexCharts.
  • Suite automatizada Karma + Jasmine (npm test, 15 pruebas) cubriendo autenticación, navegación, sandbox de pagos/PDF y reglas del Reporte Contable.

Hosting Cloudflare Pages y Hardening Web

  • Build System Version 3 con NODE_VERSION=22.23.4, comando npm run build y salida dist/ng-tailadmin/browser.
  • Cabeceras HTTP de seguridad en public/_headers: X-Frame-Options: DENY, Content-Security-Policy: frame-ancestors 'none' y Permissions-Policy restrictivo.
  • Registro público /signup retirado, idioma HTML en es, contenedor principal <main>, atributos aria-* en formularios de acceso y recuperación no destructiva ante errores de carga de chunks.
